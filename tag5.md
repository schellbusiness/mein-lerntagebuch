# Tag 5 – Neuen Branch erstellen

## Neuen Branch erstellen

`git switch -c feature2`

→ erstellt einen neuen Branch namens `feature2` und wechselt direkt auf diesen.

## Prüfen, auf welchem Branch ich bin

`git branch`

Der Stern `*` zeigt den aktuell ausgewählten Branch.

## Branch zum ersten Mal zu GitHub pushen

`git push -u origin feature2`
